My First Project: Python Calculator

My first ever coding project was done in a high school design class, and it was to create a simple python calculator. While relatively technically easy, I still find it one of my most enjoyable projects yet, as it was the first time I had ever experimented with code, and learned how to create.

My Second Project: Phonebook Dictionary

This project was completed during my first year of university here at Ontario Tech, in semester one. The goal of this project was to create a working phonebook that had full functionality as well as saving within a dictionary. Being the first real project that I had worked on in Python, this project was most certainly a learning experience.

My Third Project: Government Filing Cabinet

I completed this project during my first year at Ontario Tech, but in semester two. The objective of this program was to simulate a filing cabinet that government entities would use on its citizens for any administrative purposes needed. This was the first time that I had worked with classes as well as inheritance, and used it in the project to differentiate between citizens, such as by comparing immigrants to native residents.
