There are four CSS files in this project, indexfull, full, smartphone, and tablet. The reasoning for each choice of viewport dimension is because it is the widths that we were taught in lecture to use for their respective device. 
Indexfull is used for the home page, and is specifically used for angle linear gradient within the wrapper division; this is the only difference between indexfull and index. Both of these CSS files are designed for desktop width screens (above 960px). 
Tablet is used for any device with a screen size ranging from 481 pixels to 959. This css file is designed to accommodate for screens a little smaller than a normal desktop.
Smartphone is designed for any device with a screen that has a maximum width of 480 pixels.

Linear gradient can be found in all four of the HTML pages. This will be found specifically in the "body" area of each HTML page, and it is a gradient that goes from a light blue to a greenish blue.

Angle linear gradient can be found only on the home page. This can be seen in the wrapper of the home page, with a dark blue angular gradient at the bottom right corner, which transitions into a lighter blue that can be seen throughout the rest of the wrapper.

An Adobe colour scheme was used when creating gradients. The proof can be found in the assignment folder itself, through the file called "AdobeColor-My Color Theme".
